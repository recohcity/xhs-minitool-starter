# Ebb and Flow - 反应力测评工具

这是一个经典认知训练游戏 **"Ebb and Flow"**（潮起潮落）的 HTML5 改编版本，已改造为**60 秒反应力测评工具**（单人、无数据库、工具属性）。游戏通过经典的"任务切换"（Task-Switching）实验机制，测量玩家的 **认知灵活性 (Cognitive Flexibility)**、**反应速度** 与 **注意力控制 (Attentional Control)**。

这是一个经典认知训练游戏 **"Ebb and Flow"**（潮起潮落）的 HTML5 复刻版本。游戏旨在通过经典的“任务切换”（Task-Switching）实验机制，挑战并锻炼玩家的 **认知灵活性 (Cognitive Flexibility)** 和 **注意力控制 (Attentional Control)**。

***

## 🎮 游戏玩法与规则

1. **核心任务**：屏幕中会有一群叶子在流动。玩家需要根据叶子的**颜色**，快速交替执行两种不同的规则：
   - <span style="color: #58c27a; font-weight: bold;">● 绿色叶子 (GREEN Leaves)</span>：按叶子**指向**的方向键。
   - <span style="color: #ff9f43; font-weight: bold;">● 橙色叶子 (ORANGE Leaves)</span>：按叶子**移动**的方向键。
2. **干扰机制**：
   - **一致性场景 (Congruent)**：叶子指向的方向与移动的方向相同（如：指向右且向右移动）。
   - **冲突性场景 (Incongruent)**：叶子指向的方向与移动的方向不同（如：指向右但向左移动，此时需主动抑制无关维度的冲动）。
3. **游戏操作**：
   - **键盘控制**：使用方向键（`↑` `↓` `←` `→`）或 `W` `A` `S` `D` 键。
   - **触屏/鼠标控制**：直接在游戏区域进行\*\*滑动（Swipe）\*\*手势。
4. **积分与倍率**：
   - 每答对一次，获得 `50 × 当前倍率` 的积分。
   - 连续答对 4 次，积分倍率增加 1x（上限为 10x）。
   - 答错一次，连击归零，且倍率降低 1x，同时画面产生红光闪烁及震动反馈。
5. **限时测试**：每局测评总时长为 **60 秒**。

***

## 📊 测评与报告（改造核心）

- **60 秒三段渐进**：0-10s 适应段（以一致题为主，不计入评级）→ 10-40s 核心测量段（冲突题 50%）→ 40-60s 压力段（冲突题 70%、切换更密），难度渐进只改变试次构成比例，不污染 RT 测量；前 3 题为 Warm-up，不计分不评级。
- **受控试次生成**：切换试次约 30% 受控生成、连续同色 ≤3、四向均衡，保证 Switch Cost 等指标可计算。
- **输入清洗**：剔除 <150ms 预期反应、>3000ms 极端值与超时（4 秒自动跳题）；有效试次 ≥20 才出正式评级，异常率 >30% 提示结果受干扰。
- **专业指标**：中位 RT / 准确率 / Switch Cost / Inhibition Cost / 变异系数 CV / 综合指数 0-100（速度30+准确25+切换20+稳定15+抑制10）/ S-A-B-C-D 五档评级。
- **人话报告**：大结论（等级+指数）→ 基于本次实测值生成的个人化解读 → 针对性训练建议（含"3 天后复测"）→ 最近 5 次指数趋势（个人纵向常模）→ 专业数据折叠区。
- **分享**：Canvas 生成分享海报（S/A/B/C/D 五色），通过 `window.xhs.miniTool.postNote()` 发布；分享图仅存内存，不再写入 localStorage（避免撑爆配额）。

## 🎨 视觉与体验设计 (Design Aesthetics)

- **海洋层级背景**：渐变深蓝色海洋背景，配合多条以不同速度和方向流动的 Parallax SVG 水流线条，营造出树叶浮于水面流动的意境。
- **高保真矢量叶片**：叶片由矢量 SVG 渲染，通过精细的色块划分呈现出“左半部亮色、右半部暗色”的 3D 浮雕质感，并带有白色的描边与明亮的叶脉。
- **流畅的物理滑入/滑出 (Transitions)**：在切换关卡时，旧叶子会向其运动方向快速滑出淡化，而新叶子会从相反方向快速滑入，提供强烈的速度感与交互张力。
- **Web Audio 原生合成音效**：完全不依赖外部音频文件，使用浏览器内置 Web Audio API 实时生成音频：
  - *答对*：明快向上的双音 chime。
  - *答错*：低沉粗糙的 Sawtooth 警告音。
  - *倍率升级*：大三和弦上行琶音。
  - *倒计时警告*：最后 5 秒随时间嘀嗒报警。
  - *游戏结束*：柔和的大调和弦扫频。
- **任务切换损耗数据 (Switch Cost)**：在游戏结束后，数据面板会科学地分析出：
  - \*\*重复试次（Repeat Trials）\*\*的平均反应时间（与上一题规则相同）。
  - \*\*切换试次（Switch Trials）\*\*的平均反应时间（与上一题规则不同）。
  - **任务切换损耗（Cognitive Switching Cost）**：即在不同规则间切换时，大脑为重新配置任务集而额外付出的反应延迟（Switch RT - Repeat RT，单位为毫秒）。
- **本地排行榜**：使用 `localStorage` 持久化存储玩家历史前五的最佳战绩。

## 🚀 运行与测试

### 1. 启动本地服务器

在 `float` 目录下运行：

```bash
python3 -m http.server 8000
```

然后在浏览器中访问：`http://localhost:8000/`

### 2. 运行自动化测试

测评核心逻辑（受控试次、输入清洗、统计引擎、报告渲染、历史趋势）已通过无头浏览器端到端验证；仓库暂未提供独立测试脚本，可按上述本地服务器方式手工验证完整流程（Warm-up → 三段渐进 → 报告 → 趋势 → 分享）。

在项目根目录下运行：

```bash
./.venv/bin/python test_float_gameplay.py
```
